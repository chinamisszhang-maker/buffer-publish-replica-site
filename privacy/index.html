Privacy Policy

Effective September 12, 2026

Buffer Publish Replica is a Windows desktop application. Social account credentials and tokens are designed to remain on the user's Windows device rather than being stored by this website.

1. Scope

This policy explains how Buffer Publish Replica handles information when a user connects a social media account and uses the desktop application's publishing features. This informational website does not provide account registration, payment, or user-content hosting.

2. TikTok OAuth authorization

When a user chooses to connect TikTok, the application opens TikTok's official authorization flow. The user signs in directly with TikTok and decides whether to authorize the requested access. Buffer Publish Replica does not receive the user's TikTok password, verification code, or two-factor authentication secret.

The application may request the following TikTok scopes:

  • user.info.basic to identify the authorized account and display basic profile information such as display name and avatar.
  • video.upload to upload user-selected content as a TikTok draft.
  • video.publish to publish user-selected content when the user initiates or schedules an eligible post.

3. Access and refresh tokens

After successful OAuth authorization, TikTok may issue an access token and refresh token. On Windows, the application protects stored client and account credentials using Windows Data Protection API (DPAPI) encryption tied to the local Windows user context. Tokens are not intentionally written to ordinary plaintext configuration files, website storage, or public logs.

4. Content and account data

The application processes captions, media, scheduling details, publishing selections, basic connected-account information, and platform responses needed to perform actions requested by the user. When the user chooses to upload or publish, the selected content and required metadata are transmitted to the relevant platform through its official API.

Buffer Publish Replica does not sell personal information. Information is shared with TikTok, YouTube, or another connected platform only as needed to complete user-authorized API actions and is then governed by that platform's own terms and privacy practices.

5. Logs and diagnostics

The application may keep local operational records needed to show status and diagnose failures. Logging is designed to redact or omit access tokens, refresh tokens, client secrets, authorization codes, passwords, and verification codes. Users should not place sensitive credentials in captions or other free-text fields.

6. Storage and retention

Connected-account tokens and related local account records are retained on the Windows device while the connection is active or until the user disconnects the account, revokes authorization, removes the application's local data, or uninstalls the application. Content and scheduling records remain locally for as long as the user keeps them in the application. Third-party platforms may retain submitted content and records under their own policies.

7. Disconnect, revoke, and delete

To remove a local connection, use the application's Disconnect action for the relevant account. This removes the locally stored connection data available to the application. Users may also revoke Buffer Publish Replica in their TikTok or YouTube account settings, which prevents future API access. To remove remaining local application records, delete them through the application's available controls or remove the application's local data from the Windows user profile after closing the application.

Deleting local data does not automatically delete content already submitted to a platform. Users must manage published or draft content through that platform's controls.

8. Security

The application uses OAuth state validation, PKCE where supported, loopback callback handling for desktop authorization, encrypted local credential storage, and log redaction measures. No security method can guarantee absolute protection, and users are responsible for securing their Windows account and device.

9. Changes and support

This policy may be updated when the application's behavior or platform requirements change. The effective date above identifies the current version. For connection-data deletion assistance, first use Disconnect in the desktop application; additional support is available through the distribution channel from which the application was obtained.
