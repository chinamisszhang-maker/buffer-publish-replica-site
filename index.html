Windows desktop application

Publish with control.

Buffer Publish Replica helps users connect their own authorized social media accounts, prepare content, schedule posts, and publish videos through official platform APIs.

User-directed publishing

Account access begins only after the user completes the platform's OAuth authorization flow. Connections can be disconnected or revoked.

About

A focused desktop workflow

The application brings content preparation, scheduling, account connections, and publishing into a Windows desktop experience. Users remain responsible for their accounts, authorization choices, and submitted content.

Connect

Authorize supported social platforms through their official OAuth screens. The app never asks users to disclose platform passwords.

Prepare and schedule

Organize captions and media, review publishing details, and schedule content from the desktop application.

Publish through official APIs

Send approved content to connected accounts using the capabilities and limits provided by each platform.

TikTok integration

Explicit authorization, limited scopes

TikTok access is requested only when a user chooses to connect TikTok. TikTok displays the requested permissions and the user may allow or cancel authorization.

user.info.basic

Used to identify and display the connected TikTok account inside the application.

video.upload

Used when the user chooses to upload content as a draft for further editing and posting on TikTok.

video.publish

Used when the user expressly chooses to publish eligible content to the authorized TikTok account.

Contact / Support

Connection and data support

Users can remove a connected account and its locally stored connection data through the application's Disconnect action. Platform authorization can also be revoked from the relevant TikTok or YouTube account settings. Additional support is provided through the distribution channel from which the Windows application was obtained.
